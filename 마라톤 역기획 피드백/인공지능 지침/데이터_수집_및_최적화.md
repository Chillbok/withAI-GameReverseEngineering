# Data Collection and Optimization Guidelines

This document contains protocols for efficient data collection and token optimization for AI agents.

## 1. Web Data Collection Protocol (3 Stages)
1. **Stage 1 (Jina Reader)**: Attempt collection by prepending `https://r.jina.ai/` to the URL for token-efficient markdown extraction.
2. **Stage 2 (Direct Web Fetch)**: If Jina Reader is blocked or results are insufficient, use the `webfetch` tool directly.
3. **Stage 3 (User Assistance)**: If both methods fail, politely request the user to copy and paste the content or provide a local file.

## 2. Local Data Caching
- When fetching large amounts of data from external sources, extract core data (stat tables, rarity charts, item lists, etc.).
- Save the extracted data as markdown files in the **`게임에 대한 정보/게임 참고 자료 요약본/`** folder.
- In subsequent tasks, prioritize reading these local files instead of making web requests.

## 3. Efficient Processing
- **Sequential Processing**: Instead of analyzing multiple documents at once, process them one by one to prevent context loss.
- **Token Optimization**: Minimize AI model input costs by removing unnecessary HTML tags or advertising data.
