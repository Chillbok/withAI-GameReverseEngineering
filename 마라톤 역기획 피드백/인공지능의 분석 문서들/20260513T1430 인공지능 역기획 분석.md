# 마라톤 아이템 역기획 분석 보고서

## 1. 총평 (Summary)

> [!abstract] 요약
> 전체적인 기획 문서는 익스트랙션 슈터 장르의 핵심 압박 구조를 소모품 시스템으로 훌륭하게 녹여냈으며, 시전 시간·사운드 노출·행동 제약이라는 3중 페널티 설계는 전략성을 명확하게 강요하는 뛰어난 발상이다. 다만 **수치 명세가 대부분 "짧은 / 긴 / 상당히 긴"과 같은 모호한 서술에 그쳐 협업 가능한 기획서로서의 완결성이 낮고**, 실제 게임의 소모품 목록과 비교했을 때 누락된 아이템(Mercy Kit, Depleted Self Revive, Depleted Cardio Kick 계열 등)과 오류가 일부 확인된다. 아이템 사용 매커니즘 항목에서 임베드가 깨진 채로 방치된 점도 즉시 보완이 필요하다.

## 2. 정확성 점검 (Accuracy Check)

공식 설정 및 로컬 데이터(`게임에 대한 정보/`)와의 대조 결과입니다.

### 2.1 아이템 등급 체계

- **등급 명칭 및 순서**: **일치** — 표준·강화·호화·우수·존엄·밀수품 6단계와 각 한국어 명칭이 공식 데이터와 동일하다.
- **등급별 색상 코드**: **부분 불일치**
  - 표준: `#808080` → **일치**
  - 강화: `#00FF00` → 공식 데이터는 녹색(green)으로만 표기되어 정확한 HEX 미검증. 형광 녹색 사용은 통상 UX 관점에서 가독성 문제를 야기할 수 있음 (→ 4.1 참고).
  - 호화: `#00BFFF` → **주의** — 공식 게임의 호화(Deluxe)는 보통 하늘색 계열을 사용하나, `#00BFFF`(Deep Sky Blue)는 다소 밝은 편. 미세 오차 수준이나 공식 HEX 확인 권장.
  - 우수: `#800080` → **주의** — 공식 게임의 Superior는 보라(purple) 계열이나 `#800080`은 어두운 자주색에 가까워 실제 인게임 색상과 차이가 있을 수 있음. 확인 권장.
  - 존엄: `#FFD700` → **일치** — 골드 계열로 적절.
  - 밀수품: `#FF0000` → **일치** — 빨간색 계열로 적절.

## 3. 메커니즘 및 밸런스 분석 (Mechanism Analysis)

### 3.1 소모품 사용 페널티 설계 — 강점

익스트랙션 슈터 장르에서 소모품은 '전세 역전 카드'인 동시에 '취약함의 창출 도구'여야 한다. 이 문서에서 설계한 **시전 시간 + 사운드 노출 + 행동 제약** 3중 페널티는 이 원칙을 매우 잘 구현한 설계다.

특히 사운드 노출 설계는 타르코프와 같은 선행 작품들이 검증한 방식으로, **"아이템을 쓴다는 행위 자체가 정보가 된다"**는 정보 비대칭 게임플레이를 강화한다. 이는 단순한 페널티를 넘어 전략적 심리전의 도구가 된다.

### 3.2 치료 소모품의 보호막 우선 설계 — 논리 타당성

체력 회복 소모품이 '가성비가 나쁘게 느껴지도록' 의도적으로 설계되었고, 보호막 회복이 더 효율적인 구조는 **익스트랙션 슈터의 핵심 경제 흐름**과 잘 맞닿아 있다. 보호막이 먼저 소모되고, 체력은 더 귀중한 자원으로 기능하게 함으로써 전투에서의 긴장감을 극대화한다.

다만 **체력 회복량 수치(표준 20 / 강화 40 / 호화 80)**는 실제 플레이어 최대 체력이 몇인지 명시되지 않아서 밸런스 판단이 불가능하다. 예를 들어 최대 체력이 100이라면 표준 1개는 20%를 회복하게 되는데, 이것이 게임 흐름 내에서 적절한지 검토할 수 없다.

> [!tip] 개선 포인트
> 기획서 상단 또는 별도 섹션에 **"전제 수치 (기준값)"** 항목을 추가할 것. 최대 체력, 최대 보호막 용량, 아이템 사용 시간(초), 버프 지속 시간(초) 등의 기준값이 없으면 모든 수치 기획이 허공에 떠 있게 된다.

### 3.3 버프 소모품의 누락된 수치 — 치명적 약점

버프 소모품 전반에 걸쳐 **효과의 수치가 전혀 명시되지 않았다**. 예를 들어:

- **심폐 자극기(호화)**: "'기동성' 스테이터스를 많이 증가시킨다" → '많이'가 얼마인가?
- **에너지 증폭기(호화)**: "쿨타임을 단축함" → 몇 %를 단축하는가? 지속 시간은?
- **신호 교란기(강화)**: "모자이크 처리" → 범위, 지속 시간이 없음.

콘텐츠 기획서는 **숫자로 말할 수 있어야** 한다. 프로그래머와 협업 시 "많이", "상당히"로는 구현 불가능하다.

### 3.4 정화 소모품의 버프 부여 메커니즘 — 설계 의도는 좋으나 위험 요소 존재

정화 아이템을 사용하면 디버프를 해제함과 동시에 **스탯 버프(하드웨어/방화벽)를 부여**하는 설계는 매우 창의적이고 게임플레이적으로 흥미롭다. 디버프를 당하는 상황을 단순한 손해가 아닌 **역전의 기회**로 만들어 주기 때문이다.

그러나 **동일한 스탯 버프를 어떤 등급을 사용해도 제공한다**는 규칙(단, 지속 시간만 다름)이 명시되어 있다. 이 경우 표준 등급 아이템의 존재 이유가 매우 희박해진다 — 효과가 같고 지속 시간만 짧으면, 플레이어는 표준 아이템을 절대 선택하지 않는다.

### 3.5 퀘스트 소모품 — 완성도가 낮음

퀘스트 소모품은 스토리 연출 도구로서의 존재 이유가 명확하게 기술되어 있는 것은 긍정적이나, **아이템 종류나 사례가 단 하나도 제시되지 않았다**. 기획서로서 실체가 없는 섹션이다. "추후 추가 예정"이라도 명시하거나, 예시 아이템을 1개라도 포함해야 한다.

## 4. 기획 고도화 가이드 (Actionable Guide)

### 4.1 핵심 개선 방향

1. **수치 기준값 섹션 추가** — 모든 아이템 기획의 기반이 되는 최대 체력, 최대 보호막, 아이템 사용 시간, 스탯 영향 범위 등 기준 수치표를 메인 문서 상단에 명시.
2. **버프 수치 구체화** — "많이", "상당히" 등 모호한 표현을 실제 수치(예: 기동성 +20%, 지속 시간 15초 등)로 교체.
3. **오류 수정** — OS 디버그 강화 등급의 효과 설명 오기("물리적" → "시스템적") 수정.
4. **만병통치약 등급 표기 오류 수정** — 테이블 셀 색상이 우수(보라)가 아닌 표준(회색)으로 잘못 지정됨.
5. **안티 바이러스 팩 등급 수정** — 역기획 문서 강화 → 공식은 호화(Deluxe). 수정 또는 근거 제시 필요.
6. **깨진 임베드 복구** — 메인 문서의 "소모품 아이템 사용 매커니즘" 섹션에 임베드가 깨진 상태(`<unknown url=...>`)로 방치되어 있음. 해당 내용을 직접 서술하거나, 임베드 연결을 복구할 것.

### 4.2 개선 전/후 비교 분석 (Comparative Analysis)

| 구분 | 기존 (As-Is) | 개선 (To-Be) | 개선 사유 및 기대 효과 |
| :--- | :--- | :--- | :--- |
| **기준 수치 정의** | 없음 | 메인 문서에 "전제 수치" 섹션 추가 (예: 최대 체력 100, 최대 보호막 60 등) | 모든 회복량·버프량의 비율 계산이 가능해져 협업 및 밸런스 검토 가능. |
| **심폐 자극기 효과** | "기동성 스테이터스를 많이 증가시킨다" | "기동성 스테이터스를 +[X]만큼 증가시킨다. 지속 시간: [Y]초" | 프로그래머·QA가 구현 및 검증 가능한 형태가 됨. |
| **에너지 증폭기 효과** | "모든 플레이어 능력의 쿨타임을 단축함" | "능력 쿨타임을 [X]% 감소시킴. 효과 지속 시간: [Y]초. 이 효과 중 능력을 사용 시 해당 능력의 쿨타임도 [Z]% 감소." | 스킬 쿨타임 감소 스탯과의 중첩/별개 적용 방식이 이미 서술되어 있으나, 실제 감소율이 없어 반쪽짜리 명세임. |
| **표준 등급 정화 아이템** | 강화와 동일 효과, 지속 시간만 짧음 → 사용 동기 없음 | 표준 등급은 "즉시 디버프 해제만 제공 (스탯 버프 없음)"으로 역할 차별화, 또는 "긴급용 무거래 아이템"으로 명확히 정의 | 등급 간 명확한 역할 분담으로 플레이어의 아이템 선택에 실질적인 의사결정이 발생. |
| **OS 디버그 강화 효과 오기** | "물리적 디버프 삭제" | "시스템적 디버프 삭제" | 기획 의도를 정확히 반영, 협업자 혼란 방지. |
| **만병통치약 등급 색상** | 테이블 셀 색상이 회색(표준)으로 잘못 지정 | 보라색(우수) 셀로 수정 | 시각적 등급 시스템의 일관성 유지. |
| **안티 바이러스 팩 등급** | 강화(Enhanced)로 기재 | 호화(Deluxe)로 수정 — 단, 의도적으로 다르게 설계한 것이라면 그 근거를 주석으로 명시 | 공식 데이터와의 정합성 유지. |
| **퀘스트 소모품 섹션** | 개념 설명만 있고 아이템 사례 없음 | 예시 퀘스트 아이템 1~2개(예: "실험용 혈청", "비콘 발신기")와 연출 흐름을 간단히 서술 | 섹션이 실질적인 기획서로서의 역할을 갖게 됨. |

### 4.3 실무 적용 팁

- **색상 HEX 코드 검증**: 인게임 스크린샷 또는 공식 UI 에셋에서 직접 색상을 추출하는 것이 가장 정확하다. 현재 기재된 HEX 코드 중 일부(강화의 `#00FF00`, 우수의 `#800080`)는 UI에서 실제 쓰이는 색보다 원색에 가깝거나 어두울 수 있으므로, 에셋 추출 또는 공식 스크린샷으로 재검증을 권장한다.
- **버프 수치 설계 순서**: 수치를 결정할 때는 ① 게임 최대 스탯 확인 → ② 1회 전투에서 소모되는 평균 스탯량 추정 → ③ 아이템 1개가 복구하거나 부스팅해야 하는 비율 결정 → ④ 지속 시간 결정 순으로 진행하면 밸런스를 잡기 쉽다.
- **부활 키트 중첩 개수(1개)**: 부활 키트의 인벤토리 중첩 개수가 1개로 되어 있는데, 이는 아이템의 희귀성과 강력함을 나타내는 의도로 보인다. 다만 공식 데이터와 비교해 일치하므로 이 부분은 그대로 유지해도 좋다.
- **"소진된" 시리즈의 패턴 일관성**: 소진된 체력 키트, 소진된 실드 충전, 소진된 정비공 키트 등은 모두 표준 등급이며 탈출 시 자동 판매되는 패턴을 가진다. 심폐 자극기에만 "소진된 심폐 자극기(표준)"를 추가한 것도 이 패턴을 따른 것인데, 공식 데이터에 존재하지 않는다면 이를 명확히 "(역기획자 추정값)"으로 표기하거나, 제거를 고려하라.
- **만병통치약의 "유일한 아이템"이라는 서술**: 체력과 실드를 동시에 회복하는 유일한 아이템이라는 점을 강조하고 싶다면, 특이사항 칸에 이 내용을 남기는 것보다 **"아이템의 존재 이유" 섹션을 추가**하여 치료 소모품 카테고리 전체와의 관계를 설명하는 것이 문서 완결성에 더 도움이 된다.
